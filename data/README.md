These are the processed data files after the bioinformatics pipeline and the associated metadata files for the samples used in this study.


**Sample locations.** Positions were validated and repaired against the ship GPS tracks (`ship_tracks/`: `SR2311_combined_gps_coordinates.csv`, `SR2408_combined_gps_coordinates.csv`; UTC time, latitude, longitude). The corrected table is `processed_data/bioinformatic_outputs/geodata_corrected_MOSAIC_metadata.csv`; the correction script is not included in this repository.

**Raw sequence data.** The raw sequencing reads (FASTQ) are archived in NCBI SRA under BioProject PRJNA1556353. The processed taxon tables made from them are in `processed_data/`.
